# Technical Implementation

The packet capture mechanism was implemented using Scapy's `sniff()` function. Every captured packet is automatically forwarded to a callback function responsible for processing the packet.

Implementation workflow:

```text
Network Traffic
        │
        ▼
Scapy Packet Capture
        │
        ▼
process_packet()
        │
        ▼
Packet Summary
```

This callback-based architecture allows packet processing to remain independent of the packet capture mechanism, improving flexibility for future enhancements.

---

# Challenges Encountered

During implementation, the packet capture process initially produced a continuous stream of packet summaries. This behavior was investigated and confirmed to be expected, as modern operating systems continuously exchange network traffic even when the user is not actively browsing the internet.

Understanding this behavior provided valuable insight into real-world network communication.

---

# Key Decisions

The following implementation decisions were made during this session:

- Use Scapy for packet acquisition instead of developing a custom packet capture solution.
- Implement packet processing using callback functions.
- Capture live network traffic rather than relying on prerecorded datasets.
- Validate functionality through real-time packet observation.
