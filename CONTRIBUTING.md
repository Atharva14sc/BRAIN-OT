# Contributing to BRAIN-OT

Thank you for your interest in contributing to **BRAIN-OT (Behavioral Risk-Aware Adaptive Industrial Network Defense Platform)**.

This project follows a modular development approach. Every contribution should maintain code quality, consistency, and documentation standards.

---

## Development Workflow

1. Pull the latest version of the repository.
2. Create a separate branch for your feature or bug fix.
3. Implement the required changes.
4. Test your code before committing.
5. Submit a pull request for review.

---

## Coding Guidelines

- Follow Python best practices (PEP 8).
- Write clean, readable, and well-documented code.
- Use meaningful variable and function names.
- Keep functions modular and focused on a single task.
- Add comments only where necessary to improve clarity.

---

## Repository Structure

The project is organized into independent modules:

- `src/monitoring` – Industrial Device Monitoring
- `src/detection` – Intrusion Detection
- `src/engine` – BATI Trust Engine
- `src/response` – Automated Incident Response
- `src/dashboard` – Security Operations Center (SOC) Dashboard
- `src/utils` – Shared utility functions
- `src/config` – Configuration files

---

## Commit Messages

Use clear and descriptive commit messages.

Examples:

- `Add packet capture module`
- `Implement BATI trust calculation`
- `Improve dashboard visualization`
- `Fix anomaly detection bug`

---

## Documentation

When introducing new features:

- Update the README if necessary.
- Keep the code properly documented.
- Add comments for complex logic.
- Update TODO.md after completing major tasks.

---

## Project Goal

The objective of BRAIN-OT is to develop a modular cybersecurity platform for Industrial Control Systems (ICS) and Operational Technology (OT) environments, with the Behavioral Adaptive Trust Index (BATI) serving as the core trust evaluation mechanism.

All contributions should align with this objective.
